## 📂 Completed Tasks in this Repository

### 1. Advanced Hangman Game (Interactive GUI Edition)
* **Description:** An object-oriented, interactive desktop graphical user application built using Python's native `tkinter` library. It features category selection (Computer Science, Animals, Geography) with over 20+ expanded words per topic, real-time lives tracking, an on-screen virtual keyboard, hint assistance, and custom-centered modal pop-ups for wins and losses.
* **Key Concepts Used:** Object-Oriented Programming (OOP), `tkinter`, Event Handling, Data Structures (`dict`, `set`, `list`).

### 2. Task Automation Suite Dashboard
* **Description:** A multi-tool automation hub featuring three core scripts with an intuitive graphical interface:
  1. **JPG File Mover:** Scans a source folder directory and safely relocates all `.jpg`/`.jpeg` images to a target folder[cite: 1].
  2. **Email Address Extractor:** Reads raw `.txt` files and applies Regular Expressions (`re`) to isolate unique email addresses into clean output reports[cite: 1].
  3. **Web Title Scraper:** Fetches public web page data via HTTP `requests` and extracts `<title>` tags locally[cite: 1].
* **Key Concepts Used:** `os`, `shutil`, `re`, `requests`, File Handling, GUI Integration (`tkinter`).
